# CodePerms

Серверные права для Minecraft 1.7.10. Группы с наследованием и весами, личные ноды и мета игроков,
треки для повышения и понижения, временные выдачи, контексты (мир, измерение, оператор).

Мод заменяет встроенную json-реализацию `PermissionService` из CodeCore своей. В реестре сервисов
ядра он встаёт весом `ADDON`, то есть тяжелее встроенной реализации и наравне с другими модами прав.
Нужно поставить его выше всех: поле `servicePriority` в `config/codeperms/config.json` принимает
`BUILTIN`, `ADDON` и `OVERRIDE`.

Файл прав ядра переезжает командой `/perms import`, формат нод совпадает один в один.

Клиентской части нет: ванильный клиент заходит на сервер с CodePerms без этого мода.

## Требования

- Minecraft 1.7.10, запуск на Java 8.
- CodeCore 0.1.0 или новее, зависимость `required-after:codecore`.

## Сборка

Нужен JDK 25 (версию демона задаёт `gradle/gradle-daemon-jvm.properties`), wrapper скачает Gradle
сам. Байткод собирается под Java 8 через jabel, поэтому мод грузится на обычной 1.7.10.

```
./gradlew build
```

В `build/libs` появятся универсальный `CodePerms-0.1.0.jar` для dev-запусков и
`CodePerms-0.1.0-server.jar` для сервера. Раздавать универсальный jar игрокам нельзя: в нём
есть серверный код.

## Подключение

1. Собрать и опубликовать зависимости локально: `CodeSides` и `CodeCore` через `publishToMavenLocal`.
2. Здесь: `./gradlew build`.
3. На сервер в `mods` положить `codecore` и `CodePerms-0.1.0-server.jar`.

Права лежат в `config/codeperms/`: `config.json` с настройками, `groups.json` с группами и треками,
`players.json` с игроками. Управление через `/perms`, автодополнение и подсказки по нодам прав.

Группу, названную в `defaultGroup` или `opGroup` файла `config.json`, мод не переименовывает и не
удаляет: сначала правится настройка, иначе снимок разъехался бы с файлом. Записи, которые не влезли
в потолки из `limits`, остаются в файле нетронутыми и не попадают в модель, о каждой такой пишется
строка в лог.
